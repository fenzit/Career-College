# Карьера колледжа

Интерактивный HTML-макет карьерной платформы Digital College. Откройте `index.html` в браузере. Сборка и сервер для просмотра не нужны.

В подвале есть **Карта прототипа** со страницами, сценариями и примерами состояний. Для входа можно выбрать демонстрационный кабинет студента, компании или координатора. Между кабинетами можно переключаться через меню аккаунта.

Предложения, отклики, приглашения, публикации и настройки используют демонстрационные данные. Макет сохраняет изменения в текущем браузере. На карте прототипа можно восстановить исходные примеры.

Основной акцент `#004682` взят из логотипа Digital College.
